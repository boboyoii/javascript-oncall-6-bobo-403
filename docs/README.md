# 개발자 비상근무

## 규칙

- 닉네임 : 최대 5자
- 근무자 수 : 최소 5명, 최대 35명
- 순번 편성
  - 평일과 휴일 비상 근무 순번을 다르게 운영
  - 근무자는 평일 순번, 휴일 순번에 각각 1회 편성되어야 함
- 근무일 배정
  - 기본적 순번에 따라 배정
  - 연속 2일은 근무할 수 없음
    - 다음 근무자와 순서를 바꿔서 근무
- 년도는 고려하지 않으며, 매년 2월은 28일 까지만 있다고 가정
- 잘못 입력할 경우 다시 입력 받음

## 프로그램 흐름

1. 비상 근무 배정할 월과 시작 요일을 입력한다.
2. 평일 지상 근무 순서를 입력 받는다.
3. 휴일 비상 근무 순서를 입력 받는다.
4. 해당 월의 비상 근무표를 만든다.
5. 비상 근무표를 출력한다.

## 기능 목록

### 입력

- [x] 월과 시작 요일을 입력한다.
- [x] 평일 비상 근무 순번대로 사원 닉네임을 입력한다.
- [x] 휴일 비상 근무 순번대로 사원 닉네임을 입력한다.

### 입력값 검증

- [x] 입력한 월이 1-12사이 숫자인지 확인한다.
- [x] 입력한 요일이 월-일 값인지 확인한다.
- [ ] 닉네임이 5자가 넘지 않는지 확인한다.
- [ ] 닉네임이 중복되지 않은지 확인한다.
- [ ] 평일 순번 근무자와 휴일 순번 근무자에 각각 1회씩 편성되었는지 확인한다.
- [ ] 근무자 수가 5명 이상 35명 이하인지 확인한다.

### 비상 근무표 생성

- [ ] 평일 순번에서 비상 근무자를 배정한다.
- [ ] 휴일 순번에서 비상 근무자를 배정한다.
- [ ] 이전 근무자를 기억한다.

### 순번 관리

- [x] 순번을 저장한다.
- [x] 다음에 설 근무자를 결정한다.

### 출력

- [ ] 비상 근무표를 출력한다.
